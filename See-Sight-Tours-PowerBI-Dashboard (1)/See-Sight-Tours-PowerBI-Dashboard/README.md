# See Sight Tours – Income & Expense Analysis Dashboard

## Project Overview
This project analyzes the financial and operational performance of See Sight Tours using Microsoft Power BI. The dashboard explores tour activity, revenue, expenses, and geographical trends.

## Project Objectives
- Analyze revenue and expenses.
- Compare revenue across countries and cities.
- Explore monthly revenue trends.
- Identify the most visited tour destinations.
- Examine Revenue, Cost of Goods Sold (COGS), and Operating Expenses.

## Dataset
The dataset contains tour dates, tour codes and names, cities, countries, account groups, account descriptions, and monetary amounts.

**Important:** Only publish the dataset if you have permission to share it and it contains no confidential or personal information.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- CSV

## Data Cleaning & Preparation
- Converted columns to appropriate data types.
- Corrected the Tour Date format using the English (United States) locale.
- Split the Month-Year field for monthly analysis.
- Standardized text formatting for city, country, and tour names.
- Checked column quality for errors and missing values.

## Dashboard Features
- KPI cards: Total Tours, Total Cities, Total Revenue, Total COGS, and Operating Expenses.
- Revenue by Country.
- Tours by Codes.
- Top 5 Most Visited Places.
- Monthly Revenue.
- Amount by Account Group.
- City-level financial table.

## Key Findings
- Canada was identified as the highest revenue-generating country.
- Monthly analysis shows changes in revenue across periods.
- Tour distribution highlights the popularity of different tour categories.
- Account-group analysis compares revenue, COGS, and operating expenses.
